# 櫻井行政書士事務所（架空サイト / ポートフォリオ）

ポートフォリオ用に制作した、架空の行政書士事務所のサイトです。

## 構成：トップページ1枚（1ページ完結）

このリポジトリは **トップページ（`index.html`）1枚のみ**で構成しています。
サービス紹介・強み・代表メッセージ・お問い合わせ導線までを1ページにまとめた
ランディングページ型の作りです。

掲載している事務所名・住所・氏名・登録番号などはすべて**架空のダミー値**です。

- ページ内リンク（ヘッダー／フッターのメニュー）は、同一ページ内の各セクションへスクロールします。
- お問い合わせは `mailto:` リンクにしています（フォーム送信の実装はありません）。

## 使い方

静的サイトです。`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。

```bash
python3 -m http.server
# → http://localhost:8000/index.html
```

## 構成ファイル

- `index.html` … ページ本体
- `css/main.css` … スタイル（`main.scss` / `scss/` をコンパイルした出力）
- `script.js` … スクロール連動などの動き
- `images/` … 使用画像
