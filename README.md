# 櫻井行政書士事務所（架空サイト / ポートフォリオ）

ポートフォリオ用に制作している架空の行政書士事務所サイトです。

## ステータス：制作途中

現在は **トップページ（`index.html`）を"見せる面"** として仕上げています。
掲載している事務所名・住所・氏名・登録番号などはすべて**架空のダミー値**です。

### 見られる状態のページ
- `index.html` … トップページ（メインの見せどころ）
- `contact.html` … お問い合わせページ

### 制作途中・未実装
- 下層ページ（業務内容 / 事務所紹介 / よくあるご質問 など）
- ヘッダー / フッターのページ間統一
- お問い合わせフォームの送信処理、地図の埋め込み

## 使い方

静的サイトです。`index.html` をブラウザで開くか、任意の静的サーバーで配信してください。

```bash
python3 -m http.server
```

CSS は `scss/`（および `contact.scss` / `service.scss`）をコンパイルした結果を `css/` に出力しています。
